## Purpose

Never re-argue a settled decision.

## When to use

When the user asks what was decided about something, or asks to log a decision.

## Steps

1. Search the user's notes for decisions on the topic.
2. List each decision with its date and meeting.
3. Name the note each one comes from.

## Output format

Date · Decision · Meeting, newest first.

## Avoid

- Ideas that were discussed but not decided.
